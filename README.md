# MediVision AI

MediVision AI is a medical document and image understanding system for the LaunchPadX hackathon.

## Modules

The project consists of three main modules:
1. **X-Ray Screening**: The PRIMARY Computer Vision module.
2. **Prescription Understanding**: OCR + information extraction.
3. **Medical Bill Analysis**: OCR + structured information extraction.

## Architecture

The high-level architecture follows this flow:
User Upload → Image/Document Processing → Computer Vision / OCR → Information Extraction → Analysis → Patient-Friendly Output

## Team Development Structure

This repository is structured to allow multiple team members to work independently across frontend, backend, AI models, and data components using Git branches.
